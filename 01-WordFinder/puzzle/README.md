Karakter vectörü olarak verilen bir bulmaca içerisinde aranan kelimenin bulunup bulunmadığını (sağdan-sola, soldan-sağa, aşağıdan-yukarı, yukarıdan-aşağı, çapraz veya herhangi bir yönde serbest şekilde) veren algoritma

Örnek:
Vector = [
[xxxxxxxnxx],
[xxxxxxaxxx],
[xnxxxgxxxx],
[xxaxoxxxxx],
[xaadaxxxxx],
[xxkixxxxxx],
[xxxxfxxxxx]
]

Kelime = dogan
Output = true

Kelime = akif
Output = true

Kelime = kaan
Output = true

Kelime = kagan
Output = false
